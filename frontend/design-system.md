# Navigate 前端设计系统 v0

- 实现基线：Vue 3 Composition API + TypeScript + Vite；组件状态与数据契约均使用严格类型。

- 叙事角色：行业情报决策面，事件优先于单篇文章。
- 阅读距离：桌面端 60—80cm，高密度长时间阅读；移动端单列快速浏览。
- 视觉温度：克制、权威、带中文编辑出版物的温度。
- 色彩：象牙纸 `#F6F1E8`、正文墨色 `#191816`、酒红 `#922F50`、深酒红 `#6D1F3A`；其余仅使用中性派生色。
- 字体：中文标题使用宋体系统，正文使用苹方/黑体系统，英文识别字使用 Georgia。
- 间距：以 8px 为基础单位，资讯列表垂直间距按 18/28px 两档切换。
- 圆角：内容区保持直角；仅多来源计数使用圆形，不使用通用圆角卡片。
- 阴影：只在重点事件上使用一层低对比纸张浮层。
- 动效：160—220ms，使用 `cubic-bezier(0.22, 1, 0.36, 1)`；遵守 reduced-motion。
- 参考原则：Ground News 的事件聚合、Techmeme 的主报道与 More Sources、Feedly 的阅读队列；不复制其品牌资产或专有评分。
