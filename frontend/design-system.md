# Navigate 前端设计系统 v1 · 纸面编辑室

- 实现基线：Vue 3 Composition API + TypeScript + Vite；组件状态与数据契约均使用严格类型。
- 叙事角色：个人订阅的纸面编辑室；日报是成品，工作台是同一份纸面的编辑现场。
- 阅读距离：桌面端 60—80cm，高密度长时间阅读；移动端单列快速浏览。
- 视觉温度：克制、可印刷、带中文编辑出版物的温度。
- 色彩：画布 `#E6DFD4`、象牙纸 `#F7F2E8`、正文墨色 `#24201D`、酒红 `#722F37`、深酒红 `#5A252C`；其余仅使用中性派生色。
- 字体：中文标题使用宋体系统，正文使用苹方/黑体系统；禁止把 Inter 当作展示字。
- 间距：以 8px 为基础单位，资讯列表垂直间距按 18/28px 两档切换。
- 圆角：内容区保持直角；仅状态点使用圆形。
- 阴影：只在纸面和浮层上使用一层低对比纸张浮层。
- 动效：160—220ms，使用 `cubic-bezier(0.22, 1, 0.36, 1)`；遵守 reduced-motion。
- 图标：官方 24px 描边图标，currentColor / CSS mask；不使用 emoji 或 Unicode 替代。
- 参考原则：每日简报的刊头与篇序、Ground News 的事件聚合、Techmeme 的主报道；不复制其品牌资产或专有评分。
