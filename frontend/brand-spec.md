# Navigate 纸面编辑室设计系统

## 定位

- 叙事角色：个人订阅的纸面编辑室，不是新闻门户、也不是深色开发工作台。
- 观看距离：笔记本长时间阅读为主，手机用底栏切换栏目。
- 视觉温度：象牙纸、宋体刊头、酒红强调；像一份可以打印的行业简报。
- 容量：桌面三栏（目录 / 纸面 / 栏外索引）；窄屏收起侧栏，改用底部四栏。

## Design Decisions

- Anchor：现有每日简报的双线刊头、虚线篇序和宋体标题；工作台只是这份纸面的编辑室，而不是另一套皮肤。
- Palette：画布 `#E6DFD4`、纸面 `#F7F2E8`、纸芯 `#EEE6D8`、墨色 `#24201D`、次级 `#817972`、细线 `#D8CDBB`、品牌酒红 `#722F37`、深酒红 `#5A252C`。
- Typography：刊头与标题使用 `Songti SC / STSong / Noto Serif CJK SC`；正文使用苹方 / 黑体；日期与计数使用系统等宽。不要把 Inter 字标当作 UI 识别字。
- Spacing：4px 基础单位，主要间距 8 / 12 / 16 / 24 / 32。
- Radius：工作台保持直角；状态点才用圆形。
- Shadow：主要靠纸色差和双线刊头；浮层使用 `0 24px 70px rgba(69,52,42,.16)`。
- Motion：160–220ms，`cubic-bezier(.22,1,.36,1)`；遵守 `prefers-reduced-motion`。
- Icons：使用 `navigate-brand/icons` 的 24px 描边图标，经 CSS mask 继承当前文字色。禁止 emoji 充当图标。

## 核心布局

- 左侧 220px：几何 N 标 + Songti「Navigate」、栏目、主题速览、账号。
- 中间纸面：双线刊头、新建主题、按序号排列的文章流。
- 右侧 280px：今日概览、活动主题、额度、历史日报。
- 文章只展示来源、日期、中文标题、两行摘要和主题；不显示评分、算法解释或抓取方式。

## 品牌资产

- 图形标是官方识别：实心几何 N，酒红 `#722F37`。
- UI 中的「Navigate」用宋体排字，不使用 Inter 横版字标。
- Favicon 与 Apple Touch 使用同一图形标 / App Icon。
- 日报 masthead 内联同一 N 标，强调色与工作台统一为 `#722F37`。
