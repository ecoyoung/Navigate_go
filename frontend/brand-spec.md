# Navigate 个性化情报前端设计系统（待确认）

## 定位

- 叙事角色：个人情报工作台，不是新闻门户或算法演示页。
- 观看距离：以笔记本为主，兼顾手机；需要高阅读密度但避免终端感。
- 视觉温度：冷静、可信、略带编辑出版气质。
- 容量：桌面三栏；窄屏收起侧栏，主题筛选变为横向滑动。

## Design Decisions

- Anchor：AIHOT 的侧栏信息架构与时间流密度 + Navigate 现有编辑日报气质；不复制其 AI 分数和推荐理由。
- Palette：`#0D1117` 墨黑背景、`#151B24` 内容面、`#252E3B` 细线、`#F1EEE8` 主文字、`#9AA4B2` 次文字、`#9A3658` 酒红品牌色、`#6CB8C8` 状态强调色。
- Typography：中文正文使用系统无衬线；文章标题使用 `Songti SC / STSong`；数据和时间使用 `IBM Plex Mono` 回退到等宽系统字体。
- Spacing：4px 基础单位，主要间距为 8/12/16/24/32。
- Radius：输入器和大容器 14px，内容卡片 10px，标签 999px；避免所有元素同一圆角。
- Shadow：主要依靠边框和色差，仅主题创建浮层使用 `0 24px 70px rgba(0,0,0,.38)`。
- Motion：160–220ms，`cubic-bezier(.22,1,.36,1)`；只用于侧栏、主题切换、匹配内容进入，不使用循环动画。

## 核心布局

- 左侧 196px：NAVIGATE、为你精选、我的主题、探索、日报、收藏。
- 中间流式主栏：主题 Composer、主题 chips、按日期分组的文章流。
- 右侧 280px：今日主题摘要、来源健康、剩余额度；手机端下沉到独立抽屉。
- 文章卡片只展示来源、时间、中文标题、两行摘要、命中主题和收藏；不显示 AI 分数、算法解释或抓取方式。

## 品牌资产

- 当前使用项目既有 `NAVIGATE / 行业情报` 文字标识，不引入第三方品牌资产。
- v0 不需要照片或生成式插图；信息层次和字体是主要识别元素。
