# 进度与注意事项

当前运行时以 [项目架构](../architecture/项目架构.md) 为准。本文只记操作边界和仍然有效的限制，不把历史快照统计当现行状态。

## 现行路径

- 部署：`docker compose up -d --build`。服务为 backend、crawler、web、cloudflared。
- 数据库：`backend/data/navigate.db`。不要使用仓库根目录的空库。
- 前端：Vue 工作台请求 `/api/v1`。探索、主题、为你精选和卡片详情都读库，不读 `home.json`。
- 目录采集：北京时间 09:30 / 18:00，五种引擎。Firecrawl 不参与这轮。
- 主题发现：Search 补 URL → 引擎抽正文 → 不够再 Scrape。
- 卡片：`content_editorial_zh` + `content-editorial-validator.v6`。抓取后生成，爬虫每分钟回填漏网；日限 100、每批 2、不设 max_tokens。
- 简报：主题 `include` + 日期窗，复用卡片。导语最多 3 条头条第一句。栏目是人事/融资/监管/产品/要闻。
- 网站管理：可手动抓、可把失败源移出列表。有内容外键的源只能停用，不能物理删。

## 操作注意

- 只改库数据不用重建镜像。改 `backend/app` 或 `scripts` 要重建 `backend` 和 `crawler`。改 Vue 只重建 `web`。`cloudflared` 依赖 `web` 的网络命名空间，重建 web 会让隧道重连。
- 公网空白或登录失败时，Zero Trust Public Hostname 的 Service 填 `http://127.0.0.1:80`。
- 前台文案禁止出现额度、算法、采集过程说明。
- 中英主题匹配要覆盖复数、连字符、繁简和中文复合词；不能只拿整句去匹配。
- 卡片证据必须先清网页壳。署名、阅读时长、导航、广告追踪不能进 LLM。
- 打开简报是读路径。不要在 GET 上触发 `topic_content_editorial`。

## 已知限制

- RedFox 公众号来源全部停用，充值前不做稳定生产能力承诺。
- 部分网站 robots/挑战页/JS 壳无法用五种引擎打通，见 [不能抓取的来源](./不能抓取的来源.md)。这些源可从管理列表移除，已入库内容保留。
- 领域价值评分、实体审核台、邮件投递、支付仍不是读者主路径。
- 领域 HTML 日报 CLI（`make daily-report-zh`）服务历史治理，工作台简报不走这条。
