# Navigate 当前进度与注意事项

最后整理：2026-09-02。本文只记录当前状态；历史实验与阶段结果统一见 [归档清单](../../archive/2026-08-28-channel-cleanup/MANIFEST.md)。

## 当前正式架构

```text
sites.json 来源目录 / 用户兴趣主题
→ HTML / RSS / Sitemap / JSON API / authorized provider API
→ CrawlRun / PageSnapshot
→ RawItem / article.v1.1
→ ContentItem
→ 版本化主题匹配 / 用户合并资讯流
→ 严格重复关系
→ 多领域归属
→ 通用实体 / 别名 / 提及
→ 通用事件层
→ 独立价值评分 / 全量池与精选池
→ content_editorial.zh.v2
→ daily_edition.zh.v1
→ HTML / API
```

当前公众号在线来源均停用。RedFox API 适配器保留，便于未来在获得授权、预算和稳定性证据后重新验收；它目前不是稳定生产来源。

DeepSeek、RedFox 与 Firecrawl 的密钥统一由项目根 `.env` 或部署环境变量注入。运行时环境变量优先；`make check-secrets` 只输出配置状态和文件权限。RedFox 来源仍保持停用；Firecrawl 只在登录用户主动执行主题来源发现时调用。

RedFox 的正式选文规则以“北京时间前一自然日”为硬条件，不再使用固定顺位。列表必须翻页到早于目标日的记录或列表末尾，才算完成该日发现；日期命中后，仅依据明确布尔字段、类型或标签排除置顶和广告，不能根据 `orderNum` 或标题猜测。

## 当前重要边界

- RSS/Atom 已是网络增量同步；HTML、Sitemap、JSON API 和 Provider 仍主要依赖下载后入库幂等。
- 当前事件聚类结构可运行，但只有 2 个多篇事件，改写型同事件仍需积累人工约束样本，效果尚未证明稳定。
- LLM 编辑标签不是实体提取；聚类分、标签置信度和领域置信度不是资讯价值评分。
- 当前领域只有 beauty；混合准入器已经消除“综合来源无关文章”和“垂直来源整站放行”两类漏收，但这仍不代表通用多领域分类器已经完成。
- 用户兴趣主题已经与 Domain 解耦，可以跨行业；但当前共享池仍以已有美妆信源为主，跨行业主题要获得持续覆盖仍需审核并扩充正式来源。
- Firecrawl Search 只做候选发现，Scrape 只完成官方页面有界 canary；没有自动整站爬取，也不会因用户创建主题而自动消耗 credits。
- Firecrawl 不做自动整站抓取；用户显式发现会执行有界单页 Scrape。来源证据默认停用，只有内容自动入池，不会自动进入周期调度。
- 当前实体结果是高精度配置种子基线，只覆盖 3 个已确认实体；103 条有处理结果不等于其全部实体已经被发现。
- LLM canary 暴露出活动/栏目与 publication 等边界类型问题；未解析候选不能直接进入实体主库或事件聚类信号。
- 评分层已保存确认实体数，但当前 LLM 实体覆盖不均，v1 将该分项权重设为 0；不能让 5 篇 canary 因“被处理过”而获得额外资讯价值。
- 当前有 2 个经人工证据确认的多篇事件；自动聚类阈值没有为追求数量而降低。
- 跨来源事件当前只作为中游关系保留，不占用前台导航和独立卡片；未来有足够稳定密度后再以“热点”或“相关报道”面向读者呈现。
- 精选池是候选集，不等于日报最终栏目和位置；日报已由整期 LLM 比较标签和摘要后编排，程序级契约保证每个故事恰好出现一次。
- 浏览器只可作为未来公开 JavaScript 页面的合规渲染引擎，不能用于绕过验证码、登录、付费墙或 robots。
- 其余 9 个未打通网站自 2026-08-30 起冻结，不再进入当前开发计划；渠道层只维护已打通来源和现有合规边界。
- 244 个公众号均已有可靠 RedFox 选择器，但仍全部停用；2026-08-30 对当时 51 项清单的一次性验收余额耗尽，不能把该结果解释为稳定生产能力。
